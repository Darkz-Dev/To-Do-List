# Kanban - Gerenciador de Tarefas

Meu segundo projeto completo utilizando HTML, CSS e JavaScript puro.

O objetivo foi colocar em prática os conceitos aprendidos durante o módulo de Front-end do meu curso Full Stack, desenvolvendo uma aplicação funcional para gerenciamento de tarefas.

---

## Funcionalidades

- Criar tarefas
- Editar tarefas com duplo clique
- Excluir tarefas
- Movimentar tarefas entre as colunas
- Drag & Drop (arrastar e soltar)
- Contadores automáticos
- Data de criação de cada tarefa
- Salvar automaticamente as tarefas utilizando Local Storage
- Envio da tarefa pressionando Enter
- Layout responsivo para dispositivos móveis

---

## Observação

Durante o desenvolvimento da funcionalidade de Drag & Drop, tive dificuldade para compreender o funcionamento da API nativa do navegador.

Utilizei uma IA para me auxiliar na implementação inicial dessa funcionalidade. Depois disso, estudei o código com mais calma, busquei entender o conceito por trás de cada evento (`dragstart`, `dragover`, `drop`, `dataTransfer`, entre outros) e fiz questão de compreender como toda a lógica funciona antes de finalizar o projeto.

Meu objetivo neste projeto sempre foi aprender, e não apenas copiar uma solução pronta.
